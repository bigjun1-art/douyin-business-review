# 月度经营复盘框架

## 标题与导语

标题使用“企业简称｜YYYY年M月抖音生活服务经营复盘”。导语只说明统计周期、经营主体、数据来源和报告目的，不复述制作过程。

## 推荐结构

1. **本月结论**：3—5条最重要判断，指出增长、下滑、结构变化和主要风险。
2. **核心经营数据**：自然月与上月同口径对比表，包含成交、核销、退款、内容和直播关键指标。
3. **直播复盘**：总场次、总时长、账号数、观看、成交、券数、效率；再看账号贡献和异常。
4. **短视频复盘**：总视频、达人视频、自营/职人、发布账号、播放、互动、成交；解释数量变化和效率变化，不把数量增长直接等同效果提升。
5. **商品与门店**：头部贡献、长尾、核销与退款、承接问题。
6. **问题诊断**：只写有数据支撑的3—5个问题，区分内容供给、流量效率、转化、履约和归因。
7. **下月动作**：按重要性安排，通常压缩为三个经营阶段或三类动作；每项包含目标、负责人/对象、观察指标和停止条件。
8. **数据口径与待确认项**：列明自然月、账号范围、包含关系、去重规则和不能确认的数据。

## 写作标准

- 表格承载数据，段落承载分析；不要把分析拆成大量一句话标题。
- 环比同时给绝对值和百分比；样本小或分母为零时只给绝对变化。
- 把“发生了什么”和“为什么”分开。原因只能写有证据的驱动因素，否则写“可能原因，待验证”。
- 行动建议直接对应问题，不堆通用建议，不写用户对话、提醒或纠错记录。
- 不为凑篇幅拆日程；月度方案通常三阶段足够。
